# Architecture decision records

Use ADRs only for durable decisions with meaningful alternatives or tradeoffs.
Records are numbered sequentially, written in Markdown, and contain status,
context, decision, consequences, and alternatives. Accepted ADRs are immutable;
a later ADR supersedes rather than silently rewrites a decision.
